# 三国杀助手 · 使用说明

浏览器网页版三国杀（`web.sanguosha.com`）的辅助扩展。五项功能：

1. **记牌器** —— 通过游戏明文协议记录场上已亮的牌，面板按牌名汇总并列出最近出牌流水
2. **透视（各座位手牌）** —— 把每个座位手牌里「哪些牌已经暴露」**直接贴在座位下面**（对局中）：已知的牌名 + 未知张数；面板里另有一页按座位列出明细（含装备区 / 判定区）
3. **自动领奖** —— 调用游戏自身接口领取：七日登录、每日任务、军典/新军典、累计签到、固定日签到、斗地主军典、月卡/周卡、斗地主免费豆、邮件附件；另有「一键领取」按钮和界面「领取」按钮兜底。涉及元宝消耗/抽卡/购买的一律不自动执行。
4. **自动关弹窗** —— 自动关掉提示、公告、广告、结算、获取道具、开包动画、选皮肤、天书等弹窗；带选项的窗口（五谷丰登、奖励选择等）不碰。
5. **山河图** —— 地图节点上直接贴信息：奇遇节点显示各选项及奖励/代价；战斗节点显示战斗名 + 敌方单位 + **过关奖励**（战法/技能/卡牌/装备多选一 + 铜钱）。另外「集市」入口在每章开头就显示出来（游戏原本只在挑战首领关前才给）

只读监听游戏通信，不改游戏数据、不伪造流量、不阻断通信。涉及点击的动作默认全部关闭，需要你在面板里显式打开。

## 一、安装

扩展目录：`H:\AIWork2026\sgs-assistant`

1. 打开 Edge，地址栏输入 `edge://extensions`
2. 打开左下角（或右上角）的 **开发人员模式**
3. 点 **加载解压缩的扩展**，选择 `H:\AIWork2026\sgs-assistant`
4. 打开游戏页面，右下角会出现一个圆形「牌」按钮 —— 点它展开面板

> 如果重载扩展后按钮消失：`edge://extensions` 里把「三国杀助手」的开关重新打开一次即可（Chromium 137+ 会把命令行方式加载的扩展默认置为停用）。

## 二、面板

右下角圆形按钮展开面板，四个页签：

- **透视**：按座位列出「手牌数 / 已暴露的牌名 / 未知 ×N / 装备 / 判定」，点「实测一次」会打印服务端到底有没有下发暗牌牌面
- **记牌**：连接状态、按点数汇总、最近出牌流水
- **奖励**：自动领奖开关 + 「一键领取」+ 界面按钮兜底扫描 + 动作日志
- **设置**：
  - 记牌器 / 透视 / **座位下方贴牌面（对局中）** / 山河图显示事件名 / **山河图：集市入口常显** / 自动关闭提示弹窗 / 跳过求桃助战 / 隐藏红点 等开关
  - 关弹窗范围：`仅提示/公告/广告`（默认，保守）或 `所有非白名单窗口`
  - 「抓取当前窗口清单」：列出此刻打开的窗口，可对任意窗口点「不关它」加入白名单
  - 「重置本局记牌」

设置存在浏览器本地（`chrome.storage.local`），换页面不丢。

## 三、自动化的安全边界

**自动关弹窗**只在两个条件下动手：

1. 标准窗口层里带遮罩的窗口，且窗口名/正文命中提示特征，且窗口内有「确定/关闭/知道了」这类按钮
2. 没有独立窗口对象的提示框：只带 1~2 个关闭语义按钮、容器尺寸在 200x140 ~ 1100x720 之间、正文不含危险词与牌局交互词（选择/出牌/弃牌/使用/发动/技能/目标/结算…）

默认名单里 `MailWindow`、`ShopWindow`、`PayWindow`、`BattleWindow` 永不自动关闭。

## 五、已知限制

- **透视**能看到的边界由**服务端**决定，不由插件决定。静态分析游戏包（`sgsGame_inner.bin`）+
  真机一局（身份演武）的结论：
  - 客户端座位模型里同时存在 `handCards`（手牌牌面）、`handShowCards`（已公开手牌）、
    `visibleHandCards`（新版协议的可见手牌）、`aiHandShowCards`（明牌），渲染闸门是
    `seat.CanRenderHandCardFace(card) = CanViewHandCard || IsVisibleHandCard(card)` ——
    **「客户端知道多少」和「界面画出多少」是两件事**，插件读的是前者。
  - **暗牌牌面服务端不下发**（实测：独立监听 25 秒真实牌局，12 次「进手牌区」的移动里
    只有 1 次带真实牌 ID，且那是「获得」而不是摸牌）。所以别人的暗牌**翻不开**，
    面板只能显示「已知牌 + 未知 ×N」。
  - 反过来，**已经暴露的牌一定读得到**：`HandShowCardIDs` 是游戏自己维护的「该座位已知手牌」，
    使用 / 打出 / 弃置 / 获得 / 明牌都会进这个集合，牌离开手牌时自动移除。
  - 面板第二行就是实时结论：`serverSendsHiddenFaces` 为真时说明服务端哪天开始下发暗牌了，
    那时整手牌会自动全亮，不用改代码。
  - `ClientLookonGradeNtf` 会下发旁观等级（`LookGrade_Normal / SIDCARD / all`），旁观/观战（OB）
    身份下客户端才拿得到全场牌面 —— 那是服务端授予的，本地开不了。
- **记牌器**走游戏明文协议（劫持 `console.log` 里的 `PubGsCMoveCard`），已真机验证。面板按**牌名**汇总「已亮明」的牌，并列出最近出牌流水。
  - 协议只给**牌型 ID**（同一牌型的多张实体牌共用一个 ID），所以**无法区分具体花色点数**。
  - 「剩余某牌型」暂缺：开局牌堆 `CardList` 是槽位序号而非牌型 ID，需另找每局牌堆构成。
- **山河图事件名**已真机验证：标签贴在事件地图节点上（坐标按 canvas/stage 比例换算）。奇遇节点列出各选项及奖励/代价；战斗节点（节点 `event` 实为 Fight ID）显示战斗名 + 敌方单位（`data/rogue-fights.json`，由 `cfg_hd_roguelike` 的 `Fight`+`General` 生成）。奇遇/选择窗口打开时自动收起标签。
- **跳过求桃/助战询问**默认关闭，只在「目标不是自己」时点「取消/否」，保护救自己的求桃；尚未在真实求桃场景验证。
- **屏蔽特效**尚未实现：特效类是运行时动态类，需进对局按节点特征定位后再做。
- **自动领奖**中，敲鼓（花元宝）、元宝树、寻宝阁抽卡、礼包码、生日礼按红线不自动执行。
- 游戏界面全是 canvas（Laya 2.12.2），没有可点击的真实 DOM，所有操作走 Laya 节点 + 模拟鼠标事件。

## 六、油猴脚本版（发布到 GitHub，浏览器自动拉取最新版）

除上面的扩展版外，本仓库还能打包成**单文件油猴脚本**，用 Tampermonkey 的
`@updateURL` / `@downloadURL` 实现「发布后浏览器自动拉取最新脚本」。

### 生成

源码在 `src/`，构建脚本把它们拼成一个 userscript，并把 `data/*.json` 转成 `@require` 的 `data/*.js`：

```
node build.mjs
```

产物：

- `sgs-assistant.user.js` —— 油猴脚本本体
- `data/game-data.js` / `data/rogue-fights.js` —— 字典，作为 `@require` 随脚本一起更新

### 发布到 GitHub

1. 在 GitHub 建仓库 `sgs-assistant`（默认分支 `main`）
2. 把整个 `sgs-assistant/` 目录 push 上去（`data/*.js`、`sgs-assistant.user.js` 必须提交）
3. 若你的用户名不是 `qq398768650`：改 `build.mjs` 顶部的 `OWNER`，重跑 `node build.mjs`

### 安装（使用者）

1. 浏览器装 Tampermonkey
2. 打开 `https://fastly.jsdelivr.net/gh/<owner>/sgs-assistant@main/sgs-assistant.user.js`，
   Tampermonkey 会弹出安装页 → 安装
   （或在 Tampermonkey 面板「实用工具 → 从 URL 安装」填这个地址）

> 构建默认用 **jsDelivr（fastly 节点）** 而不是 `raw.githubusercontent.com`：后者在国内网络经常不通，
> 会导致脚本拉不到字典、也检查不到更新。若你的网络能直连 raw，可把 `build.mjs` 顶部的 `RAW` 换回
> `https://raw.githubusercontent.com/<owner>/<repo>/<branch>`。

### 自动更新

- Tampermonkey 默认每天检查一次 `@updateURL`；脚本版本号变化即自动更新脚本本体与 `@require` 字典
- 也可在 Tampermonkey 面板点「检查更新」立即拉取
- jsDelivr 对分支有缓存，push 新版后若 TM 没拉到，访问一次下面地址刷新缓存（或等几分钟）：
  `https://purge.jsdelivr.net/gh/<owner>/sgs-assistant@main/sgs-assistant.user.js`

### 发新版流程

1. 改 `src/`
2. 提升 `manifest.json` 的 `version`（构建脚本据此写进 `@version`；只改数据也要提版本，否则不触发更新）
3. `node build.mjs`
4. `git add -A && git commit -m "..." && git push`
5. 使用者的 Tampermonkey 下次检查时自动更新

> 注意：扩展版和油猴版会**双重注入**，同时开两个面板会打架，二选一。
